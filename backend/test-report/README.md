# Backend test report (HTML)

When you run `npm test` in the `backend/` folder, Jest runs the suite in `__tests__/` and **jest-html-reporter** also writes a browser-friendly summary here:

- **`index.html`** — generated each test run (do not edit by hand; it will be overwritten).

Open `backend/test-report/index.html` in a browser after tests to review pass/fail details.
